# Data Structures & Algorithms (DAKI)

**C# · .NET 6 · Utrecht University**

Original small programming assignments completed for the Utrecht University course *Datastructuren & Algoritmen*. These are console-programming exercises, not one large application.

## Projects

| Folder | Focus |
| --- | --- |
| `AirTraffic/` | Divide-and-conquer practice program |
| `Toetsenspion/` | Keystroke editor simulation using a doubly linked list |
| `Schijven/` | Algorithmic problem-solving exercise |
| `Zagerij/` | Algorithmic problem-solving exercise |
| `PlaneetX/` | Algorithmic problem-solving exercise |

## Running

Open the relevant `.sln` or `.csproj` with Visual Studio or a compatible .NET SDK. For example:

```bash
dotnet run --project Toetsenspion/Toetsenspion.csproj
```

The original assignments have not been re-tested in this environment.

## Source provenance

These are the original course source files. The browser-based Toetsenspion demo used in the portfolio is a separate later adaptation. Auto-generated build outputs and course handouts have been excluded.
